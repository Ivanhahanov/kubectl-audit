kubectl-audit-server is deployed as {{ include "kubectl-audit-server.fullname" . }} in {{ .Release.Namespace }}.

{{- if .Values.postgres.cnpg.enabled }}
Postgres is a CloudNativePG Cluster ({{ include "kubectl-audit-server.cnpgClusterName" . }})
owned by this release — requires the CNPG operator already installed
cluster-wide (this chart does not install it).
{{- else }}
Postgres: using an externally-managed database (postgres.cnpg.enabled=false).
{{- end }}

Get the admin token (needed for cluster registration and every
organization-level config endpoint):

  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.adminToken.existingSecretName | default (include "kubectl-audit-server.adminTokenSecretName" .) }} -o jsonpath='{.data.{{ .Values.adminToken.existingSecretKey }}}' | base64 -d

Register a cluster:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "kubectl-audit-server.fullname" . }} 8080:{{ .Values.service.port }} &
  curl -X POST http://localhost:8080/api/v1/clusters \
    -H "Authorization: Bearer <admin token>" -H "Content-Type: application/json" \
    -d '{"name":"my-cluster"}'


kubectl-audit-worker ({{ include "kubectl-audit-server.fullname" . }}-worker) runs the
recurring automation-rule evaluation loop (every {{ .Values.automation.intervalSeconds }}s)
as its own Deployment, separate from the server.
